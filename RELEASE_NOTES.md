# CashTab 1.0.1

First public release of CashTab, a personal Chrome new-tab desktop inspired by classic Mac interfaces.

## Features

- Plum wallpaper, translucent applications window, menu bar and a dock.
- Editable website shortcuts, favorites, ordering and recoverable link trash.
- Search or navigate to a website from the search panel.
- Local notes with autosave.
- Custom PNG/JPEG/WebP wallpapers, caption and clock preferences.
- Draggable windows and responsive layouts.
- All assets bundled; no network requests on page load and no extension permissions.

## Install / Установка

1. Download **CashTab-v1.zip** below (not the Source code archive).
2. Extract it into a permanent folder.
3. Open `chrome://extensions` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
5. Open a new tab. If another new-tab extension takes over, disable that extension first.

Скачайте **CashTab-v1.zip**, распакуйте, откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**. Выберите распакованную папку с `manifest.json`. Не удаляйте папку после установки.

## Notes

Not yet published in the Chrome Web Store. Website icons open web links; they do not launch Windows applications. Settings are local to each browser profile. UI text is currently Russian. Third-party asset credits are included in Settings → About and `ASSETS.md`.
